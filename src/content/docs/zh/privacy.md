AniShelf 是一款适用于 iPhone、iPad 和 Mac 的动画资料库管理 App。本隐私政策说明 App 会处理哪些信息、如何使用这些信息，以及你可以做出的选择。

## 摘要 {#summary}

- AniShelf 主要将你的资料库数据保存在设备上。
- 可选的 iCloud 同步会将资料库追踪数据和部分偏好设置保存在你私有的 iCloud 数据库中。
- AniShelf 无需注册 AniShelf 账号。iCloud 同步使用你的 Apple 账户，TMDb 相关功能使用你自行提供的 TMDb API 密钥。
- 搜索、元数据、图片和播出时间等功能会联系外部服务。
- AniShelf 不会出售你的个人信息。
- AniShelf 不使用第三方广告 SDK。
- AniShelf 不进行跨 App 追踪。
- AniShelf 不包含任何分析服务或自动崩溃报告服务。恢复诊断信息会保留在你的设备上，除非你主动选择分享。

## AniShelf 处理的信息 {#information}

AniShelf 可能处理以下几类信息：

### 1. 你创建的资料库数据 {#library-data}

使用 AniShelf 时，App 会保存你选择添加的信息，例如：

- 保存到资料库中的动画标题和条目
- 观看状态、进度、评分、笔记或其他资料库元数据
- 收藏、观看日期和海报选择
- 浏览、排序和语言偏好，以及保存的搜索词

这些信息通过 Apple 的系统存储技术保存在你的设备本地。如果你开启 iCloud 同步，下文所述的数据也会通过 Apple 的 CloudKit 服务同步。

### 2. 可选的 iCloud 同步 {#icloud-sync}

开启 iCloud 同步后，AniShelf 会将资料库标识符、观看状态、剧集进度、评分、收藏、笔记、观看日期、海报选择和同步时间戳上传到与你的 Apple 账户关联的私有 CloudKit 数据库。部分偏好设置（包括语言、排序、筛选和 TMDb 中转设置）也会在你的设备间同步。

获取到的作品简介和图片会在需要时重新从内容提供方获取。你的 TMDb API 密钥、保存的搜索词，以及仅限当前设备的播出提醒订阅，都不包含在 AniShelf 的 CloudKit 同步中。Apple 的服务可能会推送后台通知，以便 AniShelf 检查资料库的变更。

### 3. 你提供的 TMDb API 密钥 {#api-key}

如果你选择使用基于 TMDb 的搜索和元数据功能，可以填入你自己的 TMDb API 密钥。AniShelf 会将该密钥保存在设备的系统钥匙串中，以便 App 对发往 TMDb 的请求进行身份验证。该密钥会随 API 请求一起发送，包括经由下文所述可选中转服务器的请求。AniShelf 的资料库备份文件和 CloudKit 同步均不包含钥匙串中的这个密钥。

### 4. 搜索、元数据和播出时间请求 {#requests}

当你搜索作品或获取动画详情时，AniShelf 会将相关的请求数据发送给 The Movie Database（TMDb）或 App 使用的 TMDb 相关端点，以便返回搜索结果、简介、海报和相关元数据。

这些请求可能包含以下信息：

- 你输入的搜索词
- 所请求作品的标识符
- 获取结果所需的语言或本地化偏好

TMDb 以及参与传送这些内容的服务，可能会在这些请求中收到你的 IP 地址和标准网络元数据。

开启播出时间功能后，AniShelf 还会联系 TVMaze，以匹配节目并获取播出时间和即将播出的剧集。这些请求可能包含节目标题，以及 IMDb、TVDB 或 TVMaze 标识符。TVMaze 会收到你的 IP 地址和标准请求信息。查询播出时间时不会发送你的笔记、评分或观看进度。

请求可能在你浏览、添加或恢复条目、刷新资料库元数据或刷新播出提醒时发生，包括在后台刷新提醒时。

### 5. 可选的 TMDb 中转 {#relay}

TMDb 中转设置默认关闭。开启后，AniShelf 会将 TMDb API 请求经由 `tmdb-api.konakona.dev` 转发，而不是直接发送到 TMDb 的 API 主机。中转服务器会收到请求内容和身份验证信息（包括你的 TMDb API 密钥），以及你的 IP 地址和标准网络元数据。关闭中转后，之后的 TMDb API 请求会恢复直连。

### 6. 图片和缓存的媒体 {#images}

AniShelf 会下载你所浏览作品的海报或图片。这些图片可能会缓存在你的设备本地，以提升性能并减少重复下载。

### 7. 播出提醒 {#reminders}

如果你开启播出提醒，AniShelf 会在设备上保存你选择的节目、提醒时间和安排状态，并请求通知权限。它会从 TVMaze 获取即将播出的剧集信息，并安排本地通知。根据你的系统设置，通知可能会在锁定屏幕等位置显示节目标题和剧集信息。提醒订阅和提醒时间设置不包含在 AniShelf 的 CloudKit 同步或资料库备份的偏好设置中。

### 8. 备份、导入、导出和分享数据 {#backup}

当你使用备份、恢复、导出、导入或分享功能时，AniShelf 可能会创建包含你的资料库数据和所选 App 偏好设置（包括保存的搜索词）的文件。这些文件只会在你发起相应操作时创建。完整的资料库备份会复制本地数据库目录，也可能包含下文所述的保留恢复文件。

分享或导出的内容会通过 Apple 的系统共享表单或你选择的其他目标进行处理。数据一旦分享到 App 之外，其处理方式将受接收方服务或 App 的约束。

### 9. 恢复文件和诊断信息 {#recovery}

如果 AniShelf 无法打开本地数据库，它可能会在创建替代数据库之前，自动在你的设备上保留受影响数据库文件的副本。它还会保存一份诊断报告，包含恢复时间、错误详情、App 版本和构建号、操作系统版本，以及文件名和大小。

你可以选择导出诊断报告或恢复包。恢复包包含保留的数据库，可能含有你的资料库和笔记；报告中的错误详情可能包含本地文件路径。AniShelf 不会自动将这些文件上传给发布者。请只将它们分享给你希望接收这些信息的对象。

## AniShelf 如何使用信息 {#use}

AniShelf 使用其处理的信息来：

- 保存和显示你的动画资料库
- 记住你的设置和 App 内偏好
- 搜索 TMDb，获取作品元数据、海报和翻译
- 在开启时通过 iCloud 同步资料库追踪数据和部分偏好设置
- 获取 TVMaze 播出信息，并安排你开启的提醒
- 在你请求时创建备份和恢复资料库
- 在你请求时生成用于分享和导出的图片或文件
- 维持 App 的功能和性能
- 保留本地数据，并帮助诊断数据库恢复问题

## AniShelf 不会做的事 {#does-not-do}

AniShelf 目前不会：

- 创建用户账号
- 投放定向广告
- 出售个人信息
- 进行跨 App 追踪
- 出于营销目的有意收集使用情况分析数据
- 为 App 的日常运行有意收集精确位置、通讯录、照片、麦克风输入或相机数据

## 数据存储与保留 {#retention}

- 资料库数据和偏好设置通常保存在你的设备上。
- 如果开启了 iCloud 同步，同步的数据也会保留在你私有的 CloudKit 数据库中。关闭同步只会停止该设备上的同步，不会删除已经存储在 iCloud 中的数据。
- 同步完成后，资料库中的删除操作会同步到你的其他设备。为防止已删除的条目被旧设备恢复，会保留最少量的删除记录，包括条目标识符和删除时间。删除系列但保留其中的季时，可能会保留这些季所需的上级记录。
- TMDb API 密钥保存在设备的钥匙串中。
- 缓存的图片和临时导出文件可能会保留在设备存储中，直到被 App 或操作系统清除。
- 你创建的备份会保存在你选择保存或分享的位置。
- 关闭恢复提示后，保留的恢复数据库仍会留在设备上。删除当前资料库中的条目，不会删除这些保留的副本或单独导出的文件。
- 如果你删除 App，操作系统也可能会删除部分本地存储的数据，但你单独导出或分享的文件不会被自动删除。卸载 App 本身不会删除其 iCloud 记录，钥匙串项目也可能独立于 App 存储而保留。

## 第三方服务 {#third-parties}

AniShelf 的部分功能依赖第三方服务。

### The Movie Database（TMDb） {#tmdb}

AniShelf 使用 TMDb 提供动画搜索结果、元数据和图片。你对基于 TMDb 的功能的使用，也可能受 TMDb 的条款和隐私做法约束。

[TMDb 隐私政策](https://www.themoviedb.org/privacy-policy)

### TVMaze {#tvmaze}

AniShelf 使用 TVMaze 进行节目匹配，并获取播出时间和即将播出的剧集信息。

[TVMaze 隐私政策](https://www.tvmaze.com/site/privacy)

### Apple iCloud 和系统服务 {#apple}

AniShelf 使用 Apple 的 CloudKit 服务提供可选的 iCloud 同步，并使用 Apple 的系统服务实现通知、钥匙串存储和文件分享。Apple 对信息的处理受其自身隐私政策以及你的 Apple 账户和设备设置约束。

[Apple 隐私政策](https://www.apple.com/legal/privacy/en-ww/)

## 儿童 {#children}

AniShelf 并非面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

## 你的选择 {#choices}

你可以选择：

- 不填入 TMDb API 密钥
- 不使用基于网络的搜索和元数据功能
- 在 AniShelf 设置中开启或关闭 iCloud 同步
- 关闭 TMDb 中转，让 API 请求直接发送到 TMDb
- 关闭播出时间功能并移除播出提醒订阅
- 在系统设置中管理通知权限和通知预览
- 在 App 内删除资料库条目
- 在提供相应控制的地方删除缓存数据
- 不使用备份、导出、导入或分享功能
- 决定是否导出或分享恢复诊断信息和数据库文件
- 卸载 App

## 国际用户 {#international}

使用 AniShelf 时，发往 Apple iCloud、TMDb、TVMaze、可选中转服务器或相关内容提供方的请求，可能会根据这些提供方的基础设施和政策，在你所在国家或地区以外的地方处理。

本隐私政策可能会不时更新。如有变更，更新后的版本会连同新的生效日期一并发布。
