## 查找答案 {#answers}

[使用指南](/zh/guide/)介绍了初始设置，包括[如何申请 TMDb API 密钥](/zh/guide/#api-key)和[搜索不到结果时怎么办](/zh/guide/#tmdb-connection)。其中的[常见问题](/zh/guide/#faq)解答了大部分常见疑问。

## 联系方式 {#contact}

- **Bug 与功能建议**：请[在 GitHub 上提交 issue](https://github.com/samuelhe52/AniShelf/issues)。提交前可以先搜索一下，如果已经有人报告过，直接在那个 issue 下补充即可。
- **其他问题（包括隐私相关问题）**：请发送邮件至 [samuelhe52@outlook.com](mailto:samuelhe52@outlook.com)。没有 GitHub 账号的话，也可以通过邮件报告 Bug。

AniShelf 由一位开发者利用业余时间维护，回复可能需要几天时间，感谢理解。

## 报告 Bug {#bug-reports}

一份好的 Bug 报告应包括：

- AniShelf 的版本号，可以在“设置 › 关于AniShelf”中找到
- 你的设备型号，以及 iOS、iPadOS 或 macOS 版本
- 你做了什么、预期的结果，以及实际发生了什么
- 如果方便，附上截图或录屏

请不要附上你的 TMDb API 密钥，排查问题不需要它。

## AniShelf 无法打开资料库时 {#recovery}

如果 AniShelf 无法读取数据库，会显示 **需要恢复资料库**。它会在设备上保留无法读取的文件副本，并为你创建一个空的资料库。之前的备份或 iCloud 同步可能有助于找回数据。

如果希望开发者排查问题，请发送邮件，并附上该页面中的导出文件：

- **导出诊断信息**：生成一份简短的报告，包含错误详情、App 与系统版本，以及文件名和大小。
- **导出恢复包**：还包含保留下来的数据库，因此可能含有你的资料库和笔记。请仅在你愿意提供这些数据时发送。

所有内容都不会自动上传。详情请参阅[隐私政策](/zh/privacy/#recovery)。

## 支持开发 {#support-development}

AniShelf 免费且没有广告。如果你想支持它的开发，可以打赏：打开设置，点击 **支持 AniShelf**。
