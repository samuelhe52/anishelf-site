発効日：2026年10月2日

AniShelf は、iPhone、iPad、Mac 向けのアニメライブラリ管理アプリです。このプライバシーポリシーでは、アプリが扱う情報、その情報の使い方、そしてあなたが選べることについて説明します。

## 概要 {#summary}

- AniShelf は、ライブラリのデータを主にデバイス上に保存します。
- オプションの iCloud同期を使うと、ライブラリの記録データと一部の設定が、あなた専用の iCloud データベースに保存されます。
- AniShelf のアカウントは不要です。iCloud同期には Apple アカウントを、TMDb の機能にはあなたが用意した TMDb の API キーを使います。
- 検索、メタデータ、画像、放送時刻の機能は、外部のサービスに接続します。
- AniShelf があなたの個人情報を販売することはありません。
- AniShelf は、サードパーティの広告 SDK を使用していません。
- AniShelf は、アプリをまたいだトラッキングを行いません。
- AniShelf には、分析サービスやクラッシュの自動レポート機能は含まれていません。復旧用の診断情報は、あなたが共有を選ばない限りデバイス上に残ります。

## AniShelf が扱う情報 {#information}

AniShelf は、次の種類の情報を扱う場合があります。

### 1. あなたが作成するライブラリのデータ {#library-data}

AniShelf を使うと、アプリはあなたが追加した次のような情報を保存します。

- ライブラリに保存したアニメのタイトルと項目
- 視聴状況、進捗、スコア、ノート、そのほかのライブラリのメタデータ
- お気に入り、視聴日、ポスターの選択
- 表示、並べ替え、言語の設定と、保存された検索語

これらの情報は、Apple のシステムのストレージ技術を使ってデバイス上に保存されます。iCloud同期をオンにすると、以下で説明するデータは Apple の CloudKit サービスを通じても同期されます。

### 2. オプションの iCloud同期 {#icloud-sync}

iCloud同期をオンにすると、AniShelf はライブラリの識別子、視聴状況、エピソードの進捗、スコア、お気に入り、ノート、視聴日、ポスターの選択、同期のタイムスタンプを、あなたの Apple アカウントに関連付けられたプライベートな CloudKit データベースにアップロードします。言語、並べ替え、フィルター、TMDb 中継の設定など、一部の設定もデバイス間で同期されます。

取得済みの作品のあらすじや画像は、必要に応じてコンテンツ提供元から再取得されます。TMDb の API キー、保存された検索語、デバイスごとの放送リマインダーの登録は、AniShelf の CloudKit 同期には含まれません。AniShelf がライブラリの変更を確認できるよう、Apple のサービスがバックグラウンド通知を配信することがあります。

### 3. あなたが入力する TMDb の API キー {#api-key}

TMDb を使った検索やメタデータの機能を使う場合、ご自身の TMDb の API キーを入力できます。AniShelf は、TMDb へのリクエストを認証できるよう、このキーをデバイスのシステムキーチェーンに保存します。キーは、以下で説明するオプションの中継を経由するリクエストを含め、API リクエストとともに送信されます。キーチェーンのキーは、AniShelf のライブラリのバックアップファイルや CloudKit 同期には含まれません。

### 4. 検索、メタデータ、放送時刻のリクエスト {#requests}

作品を検索したり、アニメの詳細を取得したりすると、AniShelf は検索結果、あらすじ、ポスター、関連するメタデータを返せるよう、関連するリクエストデータを The Movie Database（TMDb）またはアプリが使う TMDb 関連のエンドポイントに送信します。

これらのリクエストには、次のような情報が含まれる場合があります。

- 入力した検索語
- リクエストした作品の識別子
- 結果の取得に必要な言語や地域の設定

TMDb や、そのコンテンツの配信に関わるサービスは、これらのリクエストの一部として、あなたの IP アドレスや標準的なネットワークのメタデータを受け取る場合があります。

放送スケジュールをオンにすると、AniShelf は番組の照合や、放送時刻と今後のエピソードの取得のために TVMaze にも接続します。これらのリクエストには、番組のタイトルや、IMDb、TVDB、TVMaze の識別子が含まれる場合があります。TVMaze は、あなたの IP アドレスと標準的なリクエスト情報を受け取ります。スケジュールの取得で、ノート、スコア、視聴の進捗が送信されることはありません。

リクエストは、項目の閲覧・追加・復元、ライブラリのメタデータの更新、放送リマインダーの更新（バックグラウンドでの更新を含む）の際に発生することがあります。

### 5. オプションの TMDb 中継 {#relay}

TMDb 中継の設定は、初期状態ではオフです。オンにすると、AniShelf は TMDb の API リクエストを、TMDb の API ホストに直接ではなく `tmdb-api.konakona.dev` 経由で送信します。中継サーバーは、リクエストの内容と認証情報（TMDb の API キーを含む）、あなたの IP アドレス、標準的なネットワークのメタデータを受け取ります。中継をオフにすると、以降の TMDb の API リクエストは直接接続に戻ります。

### 6. 画像とキャッシュされたメディア {#images}

AniShelf は、閲覧した作品のポスターや画像をダウンロードします。表示を速くし、同じ画像を何度もダウンロードしないよう、これらの画像はデバイスにキャッシュされる場合があります。

### 7. 放送リマインダー {#reminders}

放送リマインダーをオンにすると、AniShelf は選択した番組、通知のタイミング、スケジュールの状態をデバイスに保存し、通知の許可を求めます。TVMaze から今後のエピソードの情報を取得し、ローカル通知を設定します。システムの設定によっては、番組のタイトルやエピソードの情報がロック画面などの通知に表示されます。リマインダーの登録や通知のタイミングの設定は、AniShelf の CloudKit 同期やライブラリのバックアップの設定には含まれません。

### 8. バックアップ、インポート、エクスポート、共有のデータ {#backup}

バックアップ、復元、エクスポート、インポート、共有の機能を使うと、AniShelf は、ライブラリのデータと選択したアプリの設定（保存された検索語を含む）を含むファイルを作成する場合があります。これらのファイルは、あなたが操作を行ったときにのみ作成されます。ライブラリのフルバックアップはローカルのデータベースのディレクトリをコピーするもので、以下で説明する保存された復旧用ファイルが含まれる場合もあります。

共有またはエクスポートした内容は、Apple のシステムの共有シートや、あなたが選んだほかの共有先で扱われます。アプリの外に共有したデータの扱いは、共有先のサービスやアプリによって決まります。

### 9. 復旧用ファイルと診断情報 {#recovery}

AniShelf がローカルのデータベースを開けない場合、代わりのデータベースを作成する前に、影響を受けたデータベースのファイルのコピーを自動的にデバイスに保存することがあります。また、復旧の日時、エラーの詳細、アプリのバージョンとビルド、OS のバージョン、ファイル名とサイズを含む診断レポートも保存します。

診断レポートや復旧バンドルをエクスポートするかどうかは、あなたが選べます。復旧バンドルには保存されたデータベースが含まれ、ライブラリやノートが含まれる場合があります。また、レポートのエラーの詳細にはローカルのファイルパスが含まれる場合があります。AniShelf がこれらのファイルを公開者に自動でアップロードすることはありません。これらの情報を受け取ってもらいたい相手にのみ共有してください。

## AniShelf による情報の利用 {#use}

AniShelf は、扱う情報を次の目的に使います。

- アニメのライブラリを保存し、表示する
- 設定やアプリ内の好みを記憶する
- TMDb を検索し、作品のメタデータ、ポスター、翻訳を取得する
- オンにした場合に、ライブラリの記録データと一部の設定を iCloud で同期する
- TVMaze から放送情報を取得し、オンにしたリマインダーを設定する
- あなたのリクエストに応じて、バックアップを作成し、ライブラリを復元する
- あなたのリクエストに応じて、共有やエクスポート用の画像やファイルを生成する
- アプリの機能とパフォーマンスを維持する
- ローカルのデータを保護し、データベースの復旧に関する問題の診断に役立てる

## AniShelf が行わないこと {#does-not-do}

AniShelf は現在、次のことを行いません。

- ユーザーアカウントの作成
- ターゲティング広告の配信
- 個人情報の販売
- アプリをまたいだトラッキング
- マーケティングを目的とした利用状況の分析データの意図的な収集
- アプリの通常の動作のための、正確な位置情報、連絡先、写真、マイク入力、カメラのデータの意図的な収集

## データの保存と保持 {#retention}

- ライブラリのデータと設定は、通常デバイスに保存されます。
- iCloud同期がオンの場合、同期されたデータはあなた専用の CloudKit データベースにも保持されます。同期をオフにすると、そのデバイスでの同期は停止しますが、iCloud にすでに保存されたデータは削除されません。
- ライブラリでの削除は、同期が完了するとほかのデバイスにも反映されます。古いデバイスによって削除した項目が復元されないよう、項目の識別子と削除日時を含む最小限の削除記録が残ります。シーズンを残したままシリーズを削除した場合、それらのシーズンに必要な親の記録が残ることがあります。
- TMDb の API キーは、デバイスのキーチェーンに保存されます。
- キャッシュされた画像や一時的なエクスポートファイルは、アプリや OS によって消去されるまで、デバイスのストレージに残る場合があります。
- 作成したバックアップは、あなたが保存先や共有先として選んだ場所に保存されます。
- 保存された復旧用のデータベースは、復旧の通知を閉じたあともデバイスに残ります。現在のライブラリの項目を削除しても、これらの保存されたコピーや個別にエクスポートしたファイルは削除されません。
- アプリを削除すると、ローカルに保存された一部のデータも OS によって削除される場合がありますが、個別にエクスポートまたは共有したファイルは自動では削除されません。アプリのアンインストールだけでは iCloud の記録は消去されず、キーチェーンの項目はアプリのストレージとは別に残る場合があります。

## サードパーティのサービス {#third-parties}

AniShelf の一部の機能は、サードパーティのサービスを利用しています。

### The Movie Database（TMDb） {#tmdb}

AniShelf は、アニメの検索結果、メタデータ、画像の提供に TMDb を使用しています。TMDb を使った機能の利用には、TMDb の規約とプライバシーの取り扱いも適用される場合があります。

[TMDb のプライバシーポリシー](https://www.themoviedb.org/privacy-policy)

### TVMaze {#tvmaze}

AniShelf は、番組の照合、放送スケジュール、今後のエピソードの情報に TVMaze を使用しています。

[TVMaze のプライバシーポリシー](https://www.tvmaze.com/site/privacy)

### Apple の iCloud とシステムサービス {#apple}

AniShelf は、オプションの iCloud同期に Apple の CloudKit サービスを、通知、キーチェーンへの保存、ファイルの共有に Apple のシステムサービスを使用しています。Apple による情報の取り扱いには、Apple のプライバシーポリシーと、あなたの Apple アカウントやデバイスの設定が適用されます。

[Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/en-ww/)

## 子どもについて {#children}

AniShelf は 13 歳未満の子どもを対象としておらず、子どもの個人情報を意図的に収集することはありません。

## あなたが選べること {#choices}

あなたは次のことを選べます。

- TMDb の API キーを入力しない
- ネットワークを使う検索やメタデータの機能を使わない
- AniShelf の設定で iCloud同期をオン・オフにする
- TMDb 中継をオフにして、API リクエストを TMDb に直接送る
- 放送スケジュールをオフにし、放送リマインダーの登録を削除する
- システムの設定で、通知の許可とプレビューを管理する
- アプリ内でライブラリの項目を削除する
- 操作が用意されている場合に、キャッシュされたデータを削除する
- バックアップ、エクスポート、インポート、共有の機能を使わない
- 復旧用の診断情報やデータベースのファイルをエクスポート・共有するかを選ぶ
- アプリをアンインストールする

## 海外のユーザーについて {#international}

AniShelf を使うと、Apple の iCloud、TMDb、TVMaze、オプションの中継、関連するコンテンツ提供元へのリクエストが、それぞれの提供元のインフラとポリシーに従い、あなたのお住まいの国や地域以外で処理される場合があります。

## このプライバシーポリシーの変更 {#changes}

このプライバシーポリシーは、随時更新されることがあります。変更した場合は、新しい発効日とともに更新版を掲載します。
