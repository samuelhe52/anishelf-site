[ユーザーガイド](/ja/guide/)では、[TMDb の API キーの取得方法](/ja/guide/#api-key)や[検索結果が出ないときの対処法](/ja/guide/#tmdb-connection)など、初期設定について説明しています。よくある質問は[FAQ](/ja/guide/#faq)にまとめています。

## お問い合わせ {#contact}

- **不具合の報告と機能のリクエスト**：[GitHub で Issue を作成](https://github.com/samuelhe52/AniShelf/issues)してください。同じ内容がすでに報告されていないか確認し、あればその Issue に情報を追加してください。
- **そのほかのお問い合わせ（プライバシーに関するご質問を含む）**：[samuelhe52@outlook.com](mailto:samuelhe52@outlook.com) までメールでご連絡ください。GitHub アカウントをお持ちでない場合は、不具合の報告もメールで受け付けています。

AniShelf は開発者 1 人が空き時間に開発しているため、返信まで数日かかることがあります。

## 不具合を報告する {#bug-reports}

報告には、次の情報を含めてください。

- AniShelf のバージョン（設定 ›「AniShelfについて」で確認できます）
- お使いのデバイスと、iOS・iPadOS・macOS のバージョン
- 行った操作、期待していた結果、実際に起きたこと
- 可能であれば、スクリーンショットや画面収録

TMDb の API キーは含めないでください。問題の調査には必要ありません。

## ライブラリを開けないとき {#recovery}

AniShelf がデータベースを読み込めない場合、「ライブラリの復旧が必要です」と表示されます。読み込めなかったファイルのコピーをデバイスに残したうえで、空のライブラリを作成します。以前のバックアップや iCloud同期でデータを取り戻せる場合があります。

開発者に調査を依頼するときは、その画面からエクスポートしたファイルをメールに添付してください。

- **診断情報をエクスポート**：エラーの詳細、アプリとシステムのバージョン、ファイル名とサイズを含む短いレポートを作成します。
- **復旧バンドルをエクスポート**：保存されたデータベースも含まれるため、ライブラリやノートが含まれる場合があります。これらのデータを送ってもよい場合にのみ共有してください。

自動でアップロードされることはありません。詳しくは[プライバシーポリシー](/ja/privacy/#recovery)をご覧ください。

## 開発を応援する {#support-development}

AniShelf は無料で、広告もありません。開発を応援していただける場合は、設定を開いて「AniShelf をサポート」からチップを送れます。
