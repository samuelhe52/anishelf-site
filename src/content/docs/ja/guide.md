## はじめに {#setup}

AniShelf は、iOS・iPadOS 26 以降の iPhone と iPad に対応しています。Apple シリコン搭載で macOS 26 以降の Mac でも、iPad 版アプリとして動作します。

AniShelf を初めて開くと、TMDb の API キーの入力を求められます。アプリに表示されるタイトル、あらすじ、ポスター、各話の情報は The Movie Database（TMDb）から取得しています。キーは個人利用なら無料です。AniShelf は無料アプリのため共用のキーはなく、ご自身で取得していただく必要があります。

## TMDb の API キーを取得する {#api-key}

1. [The Movie Database](https://www.themoviedb.org/signup) で無料アカウントを作成します。
2. サインインして、[API の申請ページ](https://www.themoviedb.org/settings/api/request)を開きます。アカウント設定の「API」からも開けます。
3. 「Personal Use」（個人利用）を選び、フォームに入力します。
   - **Application Name**：AniShelf
   - **Application URL**：https://anishelf.konakona.dev
   - **Type of Use**：Mobile Application
   - **Application Summary**：例えば “An anime library app for tracking the series and films I watch.”
   - 連絡先を入力し、規約に同意して「Subscribe」をクリックします。
4. [API 設定ページ](https://www.themoviedb.org/settings/api)に戻り、ページ下部の「API Key」をコピーします。「API Read Access Token」（読み取りアクセストークン）ではなく、API Key を使ってください。
5. AniShelf の案内に従ってキーを貼り付けます。あとから変更するときは、設定を開いてください。

## アニメを追加する {#add}

右下の検索ボタンをタップし、シリーズや劇場版を名前で検索します。

- **シリーズ**：結果の下にあるスライダーで、シリーズ全体を追加するか、シーズンごとに追加するかを選びます。結果の右上にあるボタンでシリーズ、または 1 つ以上のシーズンを選び、「ライブラリに追加...」をタップします。
- **劇場版**：作品を選んで「ライブラリに追加...」をタップします。
- **まとめて追加**：検索画面の右上にある「一括追加」をタップし、タイトルや TMDb ID を複数入力します。

> 何回かに分けて放送されても、公式にはシーズンが分かれておらず、話数が通しになっている作品もあります。例えば『葬送のフリーレン』は「シーズン 1」に全 38 話が含まれています。このような作品は、シリーズ全体を追加してください。

## ライブラリを見る {#library}

- 左下のアイコンをタップすると、グリッド・リスト・ギャラリーの表示を切り替えられます。
- 下部中央のステータスバーで、「視聴中」など特定の視聴状況の作品だけを表示できます。
- 作品を長押しすると、そのほかの操作ができます。リスト表示では、作品を左右にスワイプして視聴状況を変更したり、削除したりできます。
- 複数の作品をまとめて変更するには、リストまたはグリッド表示で右上の「選択」をタップします。選んだ作品の視聴状況、スコア、お気に入り、日付をまとめて変更したり、削除したりできます。

## 視聴を記録する {#track}

作品をダブルタップすると詳細ページが開き、次の内容を記録できます。

- 視聴状況：見たい、視聴中、視聴済、中断
- 開始日と終了日
- エピソードの進捗
- スコアとノート

下にスクロールすると、あらすじ、キャスト、各話のあらすじを確認できます。ハートをタップするとお気に入りに追加でき、共有ボタンをタップすると友だちにおすすめするためのポスター画像を作れます。「···」メニューには、シリーズとシーズンの変換や、中断にする操作などがあります。

## 放送リマインダー {#reminders}

対象のシリーズでは、詳細ページに放送時刻が表示されます。放送中の作品なら、「···」メニューからリマインダーをオンにできます。新しいエピソードごとに、少し前、または放送時刻ちょうどに通知が届きます。AniShelf から通知の許可を求められたら、許可してください。

放送スケジュールは TVmaze から取得しているため、情報がない作品もあります。リマインダーはデバイスごとに設定します。

## 同期・バックアップ・エクスポート {#sync}

右上の設定アイコンをタップすると設定が開きます。ライブラリの概要もここで確認できます。

- **iCloud同期**：各デバイスの設定でオンにし、すべてのデバイスで同じ Apple アカウントにサインインします。ライブラリ、視聴の進捗、設定が同期されます。
- **バックアップと復元**：ライブラリと設定全体をファイルにバックアップしたり、以前のバックアップを復元したりできます。
- **書き出し**：「形式を選んで書き出し...」から、ライブラリを TXT、CSV、TSV、JSON、XLSX 形式で保存できます。

iCloud同期をオンにしていれば、[anishelf-cli](/ja/#terminal) を使ってコマンドラインからライブラリを読むこともできます。

## トラブルシューティング {#troubleshooting}

### API キーが認証されない、検索結果が出ない {#tmdb-connection}

ネットワーク環境によっては、TMDb への接続が不安定になることがあります。次の順に試してください。

1. API Read Access Token ではなく、API Key をコピーしたか確認します。
2. VPN などのネットワークプロキシをオフ、またはオンにしてみます。プロキシのルールによっては、TMDb への接続が妨げられることがあります。
3. 設定で「TMDbプロキシを使用」をオンにします。AniShelf は TMDb に直接接続する代わりに、開発者が運営する中継サーバーを経由して TMDb にリクエストを送ります。

すでに VPN やほかのプロキシを使っている場合は、「TMDbプロキシを使用」はオフのままにしてください。通常は TMDb に直接接続するほうが速く安定します。ポスターなどの画像は中継サーバーを経由しないため、ネットワーク環境によっては読み込めないことがあります。中継サーバーが受け取る情報については、[プライバシーポリシー](/ja/privacy/#relay)をご覧ください。

## よくある質問 {#faq}

### AniShelf でアニメを観たり、ダウンロードしたりできますか？ {#streaming}

できません。AniShelf は、どこで観た作品でも記録しておくためのアプリです。配信・再生、ダウンロード、エピソードへのリンクの機能はなく、マンガや小説のリーダーでもありません。

### AniList、Bangumi、TMDb と同期できますか？ {#other-services}

まだできません。ほかのサービスとの視聴データの同期は予定していますが、大がかりな作業になるため、時期は未定です。

### iOS 26 より前のバージョンに対応していますか？ {#older-versions}

対応していません。アプリのデザインに Liquid Glass を多用しているため、iOS・iPadOS 26 以降が必要です。

### Android 版はありますか？ {#android}

今のところ予定はありません。
