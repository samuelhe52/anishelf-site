## はじめに {#setup}

AniShelf は、iOS・iPadOS 26 以降の iPhone と iPad に対応しています。Apple シリコン搭載で macOS 26 以降の Mac でも、iPad 版アプリとして動作します。

AniShelf を初めて開くと、TMDb の API キーの入力を求められます。アプリに表示されるタイトル、あらすじ、ポスター、各話の情報は The Movie Database（TMDb）から取得しています。キーは個人利用なら無料です。AniShelf は無料アプリのため共用のキーはなく、ご自身で取得していただく必要があります。

## TMDb の API キーを取得する {#api-key}

1. [The Movie Database](https://www.themoviedb.org/signup) で無料アカウントを作成します。
2. サインインして、[API の申請ページ](https://www.themoviedb.org/settings/api/request)を開きます。アカウント設定の「API」からも開けます。
3. 「Personal Use」（個人利用）を選び、フォームに入力します。
   - **Application Name**：AniShelf
   - **Application URL**：https://anishelf.konakona.dev
   - **Type of Use**：Mobile Application
   - **Application Summary**：例えば “An anime library app for tracking the series and films I watch.”
   - 連絡先を入力し、規約に同意して「Subscribe」をクリックします。
4. [API 設定ページ](https://www.themoviedb.org/settings/api)に戻り、ページ下部の「API Key」をコピーします。「API Read Access Token」（読み取りアクセストークン）ではなく、API Key を使ってください。
5. AniShelf の案内に従ってキーを貼り付けます。あとから変更するときは、設定を開いてください。

## アニメを追加する {#add}

右下の検索ボタンをタップし、シリーズや劇場版を名前で検索します。

- **シリーズ**：結果の下にあるスライダーで、シリーズ全体を追加するか、シーズンごとに追加するかを選びます。結果の右上にあるボタンでシリーズ、または 1 つ以上のシーズンを選び、「ライブラリに追加...」をタップします。
- **劇場版**：作品を選んで「ライブラリに追加...」をタップします。
- **まとめて追加**：検索画面の右上にある「一括追加」をタップし、タイトルや TMDb ID を複数入力します。

> 何回かに分けて放送されても、公式にはシーズンが分かれておらず、話数が通しになっている作品もあります。例えば『葬送のフリーレン』は「シーズン 1」に全 38 話が含まれています。このような作品は、シリーズ全体を追加してください。

## ライブラリを見る {#library}

- 左下のアイコンをタップすると、グリッド・リスト・ギャラリーの表示を切り替えられます。
- 下部中央のステータスバーで、「視聴中」など特定の視聴状況の作品だけを表示できます。
- 作品を長押しすると、そのほかの操作ができます。リスト表示では、作品を左右にスワイプして視聴状況を変更したり、削除したりできます。
- 複数の作品をまとめて変更するには、リストまたはグリッド表示で右上の「選択」をタップします。選んだ作品の視聴状況、スコア、お気に入り、日付をまとめて変更したり、削除したりできます。

## 視聴を記録する {#track}

作品をダブルタップすると詳細ページが開き、次の内容を記録できます。

- 視聴状況：見たい、視聴中、視聴済、中断
- 開始日と終了日
- エピソードの進捗
- スコアとノート

エピソードの進捗は、初期設定ではオフです。オンにするには、設定を開き、「インターフェイス」で「エピソード進捗を記録」をオンにします。作品が「視聴中」のあいだ、詳細ページに進捗の操作が表示されます。この設定をオフにしても、進捗が非表示になるだけで、記録は削除されません。

下にスクロールすると、あらすじ、キャスト、各話のあらすじを確認できます。ハートをタップするとお気に入りに追加でき、共有ボタンをタップすると友だちにおすすめするためのポスター画像を作れます。「···」メニューには、シリーズとシーズンの変換や、中断にする操作などがあります。

## 再視聴する {#rewatch}

もう一度観るときは、作品の詳細ページを開き、視聴状況を「視聴済」から「視聴中」に変更します。「再視聴しますか？」と確認されます。

- 「再視聴を始める」：作品を「再視聴中」にし、エピソードの進捗をリセットします。第 1 話から再視聴を記録できます。
- 「再視聴ではない」：視聴状況だけを変更します。

再視聴中の作品を「視聴済」にすると、再視聴回数が 1 回増えます。ほかの視聴状況に変更した場合は、回数に数えずに再視聴を終了します。

視聴状況の横にあるバッジには、「2周目」のように今何周目か、または再視聴した回数が表示されます。バッジをタップすると、「再視聴中」をオン・オフしたり、「再視聴回数」を修正したりできます。ライブラリでは、「視聴済 ×2」のように視聴状況の横に回数が表示されます。

## 放送リマインダー {#reminders}

対象のシリーズでは、詳細ページに放送時刻が表示されます。放送中の作品なら、「···」メニューを開き、「通知」>「オンにする」を選びます。新しいエピソードごとに通知が届きます。AniShelf から通知の許可を求められたら、許可してください。

- **標準の通知時刻**：設定の「放送リマインダー」で、「標準の通知時刻」を放送 1 時間前から 1 時間後までの中から選びます。初期設定は 15 分前です。
- **作品ごとの通知時刻**：同じ「通知」メニューで「通知時刻」を選びます。「標準設定を使う」をオフにし、「放送前」か「放送後」を選んでから、時間と分を設定します。
- **リマインダーの管理**：設定で「リマインダー」をタップすると、すべてのリマインダーを確認し、通知時刻を変更したり削除したりできます。「更新」は最新の放送時刻でリマインダーを設定し直し、「すべて削除」はこのデバイスのリマインダーをすべて削除します。

放送スケジュールは TVmaze から取得しているため、情報がない作品もあります。リマインダーはデバイスごとに設定します。

## 同期・バックアップ・エクスポート {#sync}

右上の設定アイコンをタップすると設定が開きます。ライブラリの概要もここで確認できます。

- **iCloud同期**：各デバイスの設定でオンにし、すべてのデバイスで同じ Apple アカウントにサインインします。ライブラリ、視聴の進捗、設定が同期されます。初めてオンにするとき、どちらのデータを残すか確認されることがあります。[iCloud同期の競合を解決する](#icloud-conflict)をご覧ください。
- **バックアップと復元**：「バックアップ」は、ライブラリと設定全体を `.mallib` ファイルに保存します。TMDb の API キーは含まれません。「復元」は現在のライブラリをバックアップの内容で上書きするため、今のデータを残したい場合は先に新しいバックアップを作成してください。
- **書き出し**：「形式を選んで書き出し...」から、ライブラリを TXT、CSV、TSV、JSON、XLSX 形式で保存できます。ほかのアプリで閲覧・利用するためのファイルです。

> 復元できるのは `.mallib` バックアップだけです。書き出したファイルは AniShelf に読み込めません。バックアップを復元する前に iCloud同期をオフにし、復元後に再度オンにしてください。

## アニメ情報の言語を変更する {#language}

AniShelf では、タイトルやあらすじなどのアニメ情報を英語・中国語・日本語で表示できます。初期設定ではデバイスの言語に従います。言語を指定するには、設定を開き、「アニメ情報の言語」で「システムに従う」をオフにしてから、言語を選びます。

新しい言語が使われるのは、これから取得する情報だけです。既存の作品を更新するか確認されるので、すぐに更新するなら「更新」をタップします。ライブラリが大きいと時間がかかることがあります。あとで更新するには、設定で「情報を更新」をタップします。

iCloud同期をオンにしていれば、[anishelf-cli](/ja/#terminal) を使ってコマンドラインからライブラリを読むこともできます。

## トラブルシューティング {#troubleshooting}

### API キーが認証されない、検索結果が出ない {#tmdb-connection}

ネットワーク環境によっては、TMDb への接続が不安定になることがあります。次の順に試してください。

1. API Read Access Token ではなく、API Key をコピーしたか確認します。
2. VPN などのネットワークプロキシをオフ、またはオンにしてみます。プロキシのルールによっては、TMDb への接続が妨げられることがあります。
3. 設定で「TMDbプロキシを使用」をオンにします。AniShelf は TMDb に直接接続する代わりに、開発者が運営する中継サーバーを経由して TMDb にリクエストを送ります。

すでに VPN やほかのプロキシを使っている場合は、「TMDbプロキシを使用」はオフのままにしてください。通常は TMDb に直接接続するほうが速く安定します。ポスターなどの画像は中継サーバーを経由しないため、ネットワーク環境によっては読み込めないことがあります。中継サーバーが受け取る情報については、[プライバシーポリシー](/ja/privacy/#relay)をご覧ください。

### iCloud同期の競合を解決する {#icloud-conflict}

iCloud同期をオンにしたときや再構築したとき、AniShelf はこのデバイスと iCloud のライブラリを比較します。同じ作品のデータが両方で異なる場合、「iCloud同期の競合を解決」が表示され、対象の作品数が示されます。

- 「iCloudを使用」：対象の作品は iCloud の内容を残します。このデバイスでの変更は置き換えられます。
- 「このデバイスを使用」：このデバイスの内容を残し、iCloud にアップロードします。ほかのデバイスには次回の同期で反映されます。
- 「キャンセル」：iCloud同期をオフにします。ライブラリは変更されません。

どちらを選んでも、片方にしかない作品は残ります。どちらが正しいかわからない場合は、いったんキャンセルしてバックアップを作成してから、iCloud同期をもう一度オンにしてください。

### iCloud同期でエラーや同期の問題が表示される {#icloud-issues}

設定を開き、「iCloud同期」の下の状況を確認してください。

1. 前回の同期に失敗している場合は、「リトライ」をタップします。iCloud のストレージがいっぱいの場合は、先に空き容量を増やすかストレージプランをアップグレードしてください。
2. 状況の下に「同期の問題 3 件」のようなオレンジ色の表示がある場合は、タップすると「同期の問題」が開き、それぞれの問題の説明を確認できます。
   - **読み込めない項目**：AniShelf が自動的に再試行します。TMDb に掲載されなくなった項目は、「iCloud から削除…」で削除できます。削除はほかのデバイスにも同期されます。
   - **未アップロードの変更**：iCloud がこれらの変更を受け付けませんでした。変更はこのデバイスに残り、以降の同期で再度アップロードが試みられます。
   - **読み取れないレコード**：新しいバージョンの AniShelf で保存された可能性があります。このデバイスの AniShelf をアップデートしてください。
3. それでも解決しない場合は、設定で「iCloud同期を再構築」をタップします。AniShelf が iCloud のライブラリを再取得し、このデバイスと同期し直します。その際、[競合の解決](#icloud-conflict)を求められることがあります。

## よくある質問 {#faq}

### AniShelf でアニメを観たり、ダウンロードしたりできますか？ {#streaming}

できません。AniShelf は、どこで観た作品でも記録しておくためのアプリです。配信・再生、ダウンロード、エピソードへのリンクの機能はなく、マンガや小説のリーダーでもありません。

### AniList、Bangumi、TMDb と同期できますか？ {#other-services}

まだできません。ほかのサービスとの視聴データの同期は予定していますが、大がかりな作業になるため、時期は未定です。

### iOS 26 より前のバージョンに対応していますか？ {#older-versions}

対応していません。アプリのデザインに Liquid Glass を多用しているため、iOS・iPadOS 26 以降が必要です。

### Android 版はありますか？ {#android}

今のところ予定はありません。
